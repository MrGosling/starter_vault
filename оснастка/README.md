# Установка оснастки

Сначала прочитайте `state.py` на 69 строк: он читает файлы вашего хранилища, ничего не пишет на диск и никуда ничего не отправляет. Диалог доверия при первом запуске агента не показывает содержимое хуков, так что решение тут за вами.

```
mkdir .claude
copy оснастка\* .claude\
```

После копирования перезапустите агента.

## Две настройки оснастки

Строка `"Edit(/clippings/**)"` в блоке `permissions.deny` не даёт агенту писать в `clippings/`, куда веб-клипер кладёт файлы и где следующий клип затирает правки агента. Одна эта строка закрывает и запись, и правку, а Python для неё не нужен. Правило с путём, написанное на `Write`, наоборот, не работает и об этом не сообщает.

Ведущий слэш в пути означает корень проекта, а не корень диска. Форма `./clippings/**` привязана к текущему каталогу и не совпадёт с путём, если сессию открыли из подпапки. Тот же текст в пользовательском `~/.claude/settings.json` закроет `~/.claude/clippings`.

Хук `SessionStart` с матчером `startup|resume|clear|compact|fork` печатает три строки: сколько неразобранного в `inbox`, когда вы последний раз правили справку о системе и в скольких файлах не закрыт раздел «Что неясно».

## Что нужно, чтобы хук заработал

Хук написан на Python, поэтому проверьте, что интерпретатор стоит.

```
py -3 --version
```

Если команда открыла магазин приложений, значит Python не установлен: на Windows алиас магазина перехватывает команду `python`, запущенную без аргументов. Правило `deny` при этом продолжит работать. Хук не запустится и об ошибке не сообщит.

Команда `/hooks` внутри агента показывает событие, матчер и путь к файлу. Источником там должны стоять настройки проекта.

## Как выключить

Уберите блок `hooks` из `.claude/settings.json` или поставьте туда `"disableAllHooks": true`. Удалять `state.py`, оставив блок в настройках, нельзя, потому что хук будет падать при каждом старте сессии.

## Куда распаковывать

Держите хранилище отдельной папкой, а не внутри уже открытого проекта, потому что там агент не спросит про доверие и включит хук сам.

## Строка в брифинг проекта

В `CLAUDE.md` проекта добавьте строку: «файлы создаём и правим инструментами Write и Edit, а не через оболочку». Без неё агент пишет длинную заметку командой `cat <<EOF`, которая обрывается на первой же кавычке внутри текста, после чего работа переделывается заново.
